## 🚀 Overview

SMI AI (Smart Mind Intelligence) is a modern local AI assistant built with Python, Streamlit, and Ollama. It enables intelligent conversations using locally running language models, delivering a fast, private, and responsive AI experience without relying on cloud-based APIs.

This project represents my journey into AI engineering, LLMs, prompt engineering, and intelligent application development.
---

## ✨ Features

- 🤖 Local AI Chat powered by Ollama
- 💬 Intelligent conversational interface
- 🎨 Clean & Modern Streamlit UI
- ⚡ Fast local inference
- 🧠 Prompt categories for different use cases
- 🔄 Dynamic model selection
- 📊 Session statistics
- 🔒 Privacy-first (Runs completely offline)
